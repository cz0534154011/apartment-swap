אתר חינמי שבו משפחות מחליפות דירות לשבת או לחופשה: כל משפחה מארחת בדירה שלה ומתארחת בדירה של משפחה אחרת.
המערכת מלאה מקצה לקצה: חיפוש, לוח תפוסה, הצעות החלפה עם תהליך אישור וביטול, ומסכי ניהול.

## בדיקה מהירה (כ-5 דקות)

1. **אורח:** בדף הבית, לפתוח את "סינון וחיפוש" ולסנן לפי עיר, תאריכים ואביזרי שבת. להיכנס לדירה ולראות את לוח התפוסה.
2. **cohen:** בדירה של levi, ללחוץ "שליחת הצעה", לבחור תאריכים ולשלוח.
3. **levi:** "ההחלפות שלי", לשונית "קיבלתי", "לפרטים": פרטי הקשר של cohen, ולאשר. התאריכים נצבעים בלוח של שתי הדירות.
4. **cohen:** באותה החלפה, "בקשת ביטול" עם סיבה. אצל levi ההצעה מסומנת בפס כתום עד שיסכים או יסרב.
5. **cohen:** "לוח התפוסה שלי": לחסום תאריכים, ולראות אותם בלוח וברשימה.
6. **מנהל:** "ניהול דירות", לחסום את הדירה של cohen. אצל cohen, ב"הדירה שלי", מופיעה הודעת חסימה עם הסיבה.

## חשיבה מערכתית

- **הרשאות בשני מקומות:** התפריט משתנה לפי התפקיד, וכל נתיב מוגן גם בכתובת: אורח מועבר להתחברות, ומשתמש בלי הרשאה מועבר לדף הבית.
- **הכל מתעדכן מיד:** אחרי כל פעולה (אישור, חסימה, ביטול) מתעדכנים הרשימות, הלוחות והכותרת, בלי רענון.
- **השרת הוא מקור האמת:** הכפתורים בהחלפה נקבעים לפי מה שהשרת מתיר, ושגיאות השרת מוצגות בעברית.
- **כל מסך מטפל בכל המצבים:** טעינה, שגיאה, רשימה ריקה, והצלחה.
- **בלי כפל קוד:** רכיבים משותפים (שדה טופס, מעבר עמודים, תגית סטטוס, לוח תפוסה, תיבת פרטי קשר), Hooks משותפים (פרטי האתר, הדירה שלי), וטיפוסים משותפים (רשימה עם עמודים).
- **עברית ונגישות:** מימין לשמאל, מותאם לטלפון, מייל ותאריכים מוצגים נכון בתוך טקסט עברי, ומיקוד ברור במקלדת.

## עמידה בדרישות

כל 15 המסכים שהוגדרו לפרויקט מומשו, לפי כללי השרת ומדריך ה-API, ובנוסף:
- הודעות לכל מצב שהשרת מגדיר (חסימה, עיר בשימוש, הצעות שנדחו אוטומטית).
- עמוד דוגמאות לכל רכיבי העיצוב: `client/style-guide.html`, ומדריך מחלקות: `client/CSS-CLASSES.md`.
- השרת כולל בדיקות אוטומטיות ותיעוד Swagger מלא.
- האתר והשרת פועלים בענן.

## הרצה במחשב

```
cd backend
npm install
npm run db:deploy
npm run db:seed
npm run dev

cd client
npm install
npm run dev
```

לפני ההרצה: בשרת, קובץ `.env` לפי `backend/.env.example`. באתר, קובץ `client/.env` עם השורה `VITE_API_URL=http://localhost:3000/api`.
האתר נפתח בכתובת http://localhost:5173.
