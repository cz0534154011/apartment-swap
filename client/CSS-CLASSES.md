# מדריך מחלקות CSS - אתר החלפת דירות

כל העיצוב נמצא בתיקייה `client/src/styles/`. אין צורך לכתוב CSS בתוך הקומפוננטות, רק לשים את שמות המחלקות.

עמוד דוגמאות חי: `http://localhost:5173/style-guide.html` (כשהשרת של Vite רץ).

**איך לקרוא את הטבלאות:** בעמודה הימנית תיאור האלמנט, בעמודה השמאלית המחלקה שיש לשים עליו. גרסה (למשל `btn--primary`) תמיד באה **בנוסף** למחלקה הבסיסית (`btn`), לא במקומה.

---

## 1. מעטפת האתר

**איפה:** בקומפוננטת ה-Layout שעוטפת את כל המסכים.

| אלמנט | מחלקה |
|---|---|
| ה-div החיצוני של כל האתר | `site` |
| התגית `header` העליונה | `site-header` |
| ה-div שבתוך ה-header (מרכז את התוכן) | `site-header__inner` |
| הקישור עם שם האתר | `site-header__brand` |
| אותו קישור, כשיש בו שורת הסבר (בנוסף ל-`site-header__brand`) | `site-header__brand--with-tagline` |
| `span` בתוך הקישור, עם שם האתר | `site-header__name` |
| `span` בתוך הקישור, מתחת לשם, עם שורת ההסבר | `site-header__tagline` |
| אזור המשתמש המחובר (שם + כפתור יציאה) | `site-header__user` |
| התגית `nav` | `site-nav` |
| ה-`ul` של התפריט | `site-nav__list` |
| כל קישור בתפריט | `site-nav__link` |
| התגית `main` | `site-main` |
| התגית `footer` | `site-footer` |
| ה-div שבתוך ה-footer | `site-footer__inner` |
| ה-`ul` של הקישורים בתחתית | `site-footer__links` |

**קישור פעיל בתפריט:** אם משתמשים ב-`NavLink` של React Router, הוא מוסיף לבד את המחלקה `active` ואת `aria-current="page"`, והעיצוב כבר תומך בהם. אין צורך להוסיף כלום. אפשר גם להוסיף ידנית `site-nav__link--active`.

**בטלפון:** התפריט יורד לשורה שנייה ונגלל ימינה-שמאלה בתוך עצמו.

**מחלקות נוספות:**
- `container`: אזור ממורכז ברוחב מקסימלי (אם צריך מחוץ ל-`site-main`).
- `container--narrow` (בנוסף ל-`container`): אזור צר, מתאים לטופס התחברות והרשמה.

## 4. כפתורים

**איפה:** בכל האתר. מתאים לתגית `button` וגם לקישור `a` שנראה ככפתור.

| מה רוצים | מחלקות |
|---|---|
| כפתור ראשי (שמירה, שליחה, חיפוש) | `btn btn--primary` |
| כפתור משני (עריכה, לפרטים) | `btn btn--secondary` |
| כפתור מסוכן (מחיקה, דחייה, ביטול החלפה) | `btn btn--danger` |
| כפתור שקוף/טקסט (ביטול, סגירה, יציאה) | `btn btn--ghost` |
| כפתור קטן | להוסיף גם `btn--small` |
| כפתור ברוחב מלא | להוסיף גם `btn--block` |

**מצבים:**
- **מנוטרל:** המאפיין `disabled` על ה-`button`. העיצוב מגיע לבד.
- **בטעינה (בזמן שליחה):** להוסיף `btn--loading`, או המאפיין `aria-busy="true"`. מופיע סמל מסתובב לפני הטקסט. מומלץ לנטרל את הכפתור באותו זמן.

**קבוצת כפתורים בשורה:** ה-div שעוטף אותם מקבל `btn-group`. אם רוצים שבטלפון כל כפתור יהיה בשורה משלו ברוחב מלא, להוסיף גם `btn-group--stack-mobile`.

## 5. טפסים

**איפה:** הרשמה, התחברות, הדירה שלי, פרופיל, צור קשר, חלון שליחת הצעה, ניהול ערים.

| אלמנט | מחלקה |
|---|---|
| התגית `form` | `form` |
| div שמכיל שני שדות זה לצד זה (בטלפון אחד מתחת לשני) | `form__row` |
| ה-div שעוטף שדה אחד | `field` |
| ה-`label` | `field__label` |
| כוכבית "שדה חובה" בתוך התווית (`span`) | `field__required` |
| ה-`input`, `select` או `textarea` | `field__input` |
| טקסט עזר מתחת לשדה | `field__hint` |
| הודעת השגיאה מתחת לשדה | `field__error` |
| תזכורת בולטת מעל כפתור השמירה | `form__warning` |
| ה-div של הכפתורים בתחתית הטופס | `form__actions` |

**שדה שגוי:** שתי אפשרויות (אפשר את שתיהן):
- להוסיף `field--error` ל-div של השדה (בנוסף ל-`field`).
- לשים על הקלט את המאפיין `aria-invalid="true"` כשיש שגיאה. זה גם טוב לנגישות.

שדות מסוג `number`, `date`, `email`, `tel` נכתבים אוטומטית משמאל לימין.

**תיבות סימון:**

| אלמנט | מחלקה |
|---|---|
| ה-`label` שעוטף את ה-`input` מסוג checkbox ואת הטקסט | `checkbox` |
| div שעוטף כמה תיבות סימון (אביזרי שבת) ומסדר אותן ברשת | `checkbox-group` |
| התגית `fieldset` שעוטפת את הקבוצה | `fieldset` |
| התגית `legend` (כותרת הקבוצה) | `fieldset__legend` |

ה-`input` עצמו לא צריך מחלקה. לתיבה מנוטרלת: להוסיף `checkbox--disabled` ל-label.

**שדה סיסמה עם כפתור הצגה** (הרשמה, התחברות):

| אלמנט | מחלקה |
|---|---|
| `div` חדש שעוטף רק את ה-`input` ואת הכפתור (בתוך ה-`field`) | `password-field` |
| ה-`input` עצמו | `field__input` (כרגיל) |
| ה-`button` שבתוכו (אחרי ה-input) | `password-field__toggle` |

הכפתור מופיע בתוך השדה, בצד שמאל. חשוב לתת לו `type="button"`, אחרת הוא ישלח את הטופס.

**תקנון שנפתח ונסגר בתוך הטופס** (טופס ההרשמה, מעל תיבת אישור התקנון):

| אלמנט | מחלקה |
|---|---|
| התגית `details` | `terms-box` |
| התגית `summary` בתוכה (הטקסט שלוחצים עליו) | `terms-box__summary` |
| פסקה עם טקסט התקנון, אחרי ה-summary | `terms-box__text` |

התגית `details` נפתחת ונסגרת לבד בלחיצה, בלי state. לטקסט הארוך יש גלילה פנימית.

## 9. תגיות סטטוס

**איפה:** ההחלפות שלי, פרטי החלפה, כל ההחלפות (מנהל).

תמיד `badge`, ובנוסף אחת מהגרסאות:

| סטטוס בשרת | טקסט | מחלקה נוספת |
|---|---|---|
| PENDING | ממתינה | `badge--pending` |
| APPROVED | מאושרת | `badge--approved` |
| REJECTED | נדחתה | `badge--rejected` |
| AUTO_REJECTED | נדחתה אוטומטית | `badge--auto-rejected` |
| WITHDRAWN | נמשכה | `badge--withdrawn` |
| CANCELLED | בוטלה | `badge--cancelled` |
| EXPIRED | פג תוקף | `badge--expired` |
| בקשת ביטול פתוחה | בקשת ביטול פתוחה | `badge--cancel-request` |

שם המחלקה הוא שם הסטטוס באותיות קטנות, עם מקף במקום קו תחתון. את `badge--cancel-request` מציגים ליד תגית הסטטוס הרגילה.

לנגישות: להודעת שגיאה כדאי `role="alert"`, לשאר `role="status"`.

## 19. חלון קופץ

**איפה:** שליחת הצעה, אישור מחיקה/דחייה/ביטול.

שתי דרכים, בחר אחת:

**דרך א: התגית `dialog`** (פותחים עם `showModal`). שים על ה-`dialog` את המחלקה `modal`. הרקע הכהה מגיע לבד.

**דרך ב: div רגיל.** div חיצוני עם `modal-backdrop` (הרקע הכהה על כל המסך), ובתוכו div עם `modal`.

החלקים בתוך החלון (בשתי הדרכים):

| אלמנט | מחלקה |
|---|---|
| ה-div העליון (כותרת + כפתור סגירה) | `modal__header` |
| הכותרת | `modal__title` |
| כפתור הסגירה (X) | `modal__close` |
| תוכן החלון | `modal__body` |
| ה-div של הכפתורים למטה | `modal__actions` |

גרסה: `modal--small` לחלון אישור קצר ("האם אתה בטוח?").

בדרך ב כדאי להוסיף ל-`body` את המחלקה `modal-open` כשהחלון פתוח, כדי שהעמוד מאחור לא ייגלל. לנגישות: לשים על ה-div של החלון `role="dialog"` ו-`aria-modal="true"`, ועל כפתור הסגירה `aria-label="סגירה"`.

## 20. לוח תפוסה (react-day-picker)

**איפה:** פרטי דירה, לוח התפוסה שלי.

העיצוב של הספרייה כבר מותאם לצבעי האתר. אין צורך במחלקות על הלוח עצמו.

| אלמנט | מחלקה |
|---|---|
| div שעוטף את הלוח (מסגרת לבנה, אופציונלי) | `calendar` |

**ימים מסומנים:** מעבירים לקומפוננטה של הלוח את `modifiers` (אילו תאריכים) ואת `modifiersClassNames` (איזו מחלקה לכל סוג). שמות המחלקות:

| סוג יום | מחלקה |
|---|---|
| החלפה מאושרת | `day--swap` |
| חסימה ידנית | `day--blocked` |
| הצעה ממתינה (רק לבעל הדירה) | `day--pending` |

ימים מנוטרלים (עבר, מעבר ל-6 חודשים) נראים דהויים לבד, דרך `disabled` של הספרייה.

כדי שהלוח יהיה מימין לשמאל, להעביר לקומפוננטה `dir="rtl"` (ואת ה-locale העברי של date-fns, אם רוצים שמות חודשים בעברית).

**מקרא מתחת ללוח:**

| אלמנט | מחלקה |
|---|---|
| ה-`ul` | `calendar-legend` |
| כל `li` | `calendar-legend__item` |
| הריבוע הצבעוני (`span` ריק) | `calendar-legend__swatch` + סוג |

סוגי ריבוע: `calendar-legend__swatch--free` (פנוי), `--swap`, `--blocked`, `--pending`, `--disabled`. למשל: `calendar-legend__swatch calendar-legend__swatch--swap`.

## 21. מחלקות עזר

| מחלקה | מה עושה |
|---|---|
| `ltr` | מייל, טלפון, מספרים ותאריכים בתוך טקסט עברי (כתיבה משמאל לימין) |
| `visually-hidden` | טקסט שרק קוראי מסך רואים |
| `text-muted` | טקסט אפור משני |
| `text-small` | טקסט קטן |
| `text-center` / `text-start` | יישור טקסט |
| `text-bold` | טקסט מודגש |
| `mt-0`, `mt-sm`, `mt-md`, `mt-lg` | רווח מעל |
| `mb-0`, `mb-sm`, `mb-md`, `mb-lg` | רווח מתחת |

---

## 22. שינוי המראה

כל הצבעים, הגופנים, הרווחים והפינות נמצאים בקובץ `tokens.css`. שינוי ערך שם משנה את כל האתר. למשל, לשינוי הצבע הראשי: לשנות את `--color-primary`.

נקודות שבירה: 640px (טאבלט) ו-1024px (מחשב).

---

## 23. איך לייבא את הקבצים

בקובץ `client/src/main.tsx`:

1. להוסיף שורת import לקובץ העיצוב של הספרייה: `react-day-picker/style.css`.
2. מתחתיה, להוסיף שורת import לקובץ `./styles/global.css`.

הסדר חשוב: קובץ הספרייה קודם, ואחריו `global.css`, כדי שהעיצוב של האתר ידרוס את העיצוב של הספרייה.

3. למחוק את שורת ה-import של `./index.css` (הקובץ שהגיע עם Vite), כדי שלא יתנגש. גם ב-`App.tsx` למחוק את שורת ה-import של `./App.css`.

את שאר קבצי ה-CSS לא מייבאים בקוד. `global.css` מייבא אותם לבד.
